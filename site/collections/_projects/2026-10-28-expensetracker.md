If login is successful, user will be directed to recent expenses tab, this tab shows last 7 days expenses.

![](/uploads/expense-tracker-recent-expenses.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

And all expenses tab shows all expenses that user has.

![](/uploads/expense-tracker-all-expenses.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

User can add a new expense by add expense form.

![](/uploads/expense-tracker-add-expense-form-1.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

There will be a camera permission pop up when user click "Take Image" for the first time.

![](/uploads/expense-tracker-camera-permission.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

After user clicked "While using the app" or "Only this time", they will directly can use camera to capture an image.

![](/uploads/expense-tracker-camera-open.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

After user captured an image, they can choose between "Ok" to use the image or "Retry" to recapture image again.

![](/uploads/expense-tracker-camera-clicked.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

If user clicked "Ok", user can adjust to crop the image based on app ratio.

![](/uploads/expense-tracker-camera-crop.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

Below part of add expense form is location input.

![](/uploads/expense-tracker-add-expense-form-2.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

There will be a location permission pop up when user click "Use Current Location" for the first time.

![](/uploads/expense-tracker-location-permission.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

If user clicked "Don't Allow" there will be this warning pop up after that.

![](/uploads/expense-tracker-permission-first-don't-allow.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

If user clicked "Don't Allow" again for the second time, there will be another warning which provide a button that will direct user to thier phone settings, then User can choose "Permissions".

![](/uploads/expense-tracker-permission-second-don't-allow.jpg){: width="48%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-direct-settings.jpg){: width="48%" style="max-width:100%; height:auto;"}

User can see what apps are allowed and not allowed in each list and choose which apps want to be allowed and not allowed.

![](/uploads/expense-tracker-permissions-settings.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

These are the options inside every app in app permissions.

![](/uploads/expense-tracker-location-permission-settings.jpg){: width="48%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-allow-location-permission-settings.jpg){: width="48%" style="max-width:100%; height:auto;"}

If user chose "Allow only while using this app" or "Ask everytime", when they clicked back, they will directly can use location to select. The location screen will show Latitude and Longitude after user clicked "Use Current Location".

![](/uploads/expense-tracker-use-current-location.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

If user clicked "Choose Location on Map" they will be directed to map and they can choose as they want then click the save icon on the top right corner. After that the location screen will also show Latitude and Longitude based on user selection in the map.

![](/uploads/expense-tracker-choose-location-on-map.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

After user clicked "Add" button, they will be directed to recent expenses tab, and there will be added notification with expense's description too.

![](/uploads/expense-tracker-added-expense-notification.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

The new expense will be added to all expenses tab if the date is more than 7 days.

![](/uploads/expense-tracker-added-new-expense.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

We also can edit expense if we want to. For example I edited the amount of this expense.

![](/uploads/expense-tracker-edit-expense_form_1.jpg){: width="32%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-edit-expense_form_2.jpg){: width="32%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-edit-expense_form_3.jpg){: width="32%" style="max-width:100%; height:auto;"}

After user clicked "Update" button, they will be directed to all expenses tab, and there will be updated notification with expense's description too.

![](/uploads/expense-tracker-updated-expense-notification.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

We also can delete expense if we want to. For example I want to delete this expense.

![](/uploads/expense-tracker-delete-expense_form_1.jpg){: width="48%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-delete-expense_form_2.jpg){: width="48%" style="max-width:100%; height:auto;"}

After user clicked the trash icon, they will be directed to all expenses tab, and there will be deleted notification with expense's description too.

![](/uploads/expense-tracker-deleted-expense-notification.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

And since the deleted expense is included in last 7 days, the same expense is also deleted in recent expenses tab.

![](/uploads/expense-tracker-recent-expense_after_deleted.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}

Both either in recent expense tab or all expense tab, user could see a logout icon on the top right corner which they can click to logout.

![](/uploads/expense-tracker-recent-expense_after_deleted.jpg){: width="48%" style="max-width:100%; height:auto;"} ![](/uploads/expense-tracker-logout-button.jpg){: width="48%" style="max-width:100%; height:auto;"}

After user successfully logout, they will be directed to login form again.

![](/uploads/expense-tracker-login-form.jpg){: width="48%" style="max-width:100%; height:auto; display:block; margin:0 auto;"}
